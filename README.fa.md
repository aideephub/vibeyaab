# VibeYaab — قبل از ساختن، پیدا کن

[English](./README.md) | **فارسی**

### ▶️ [برنامهٔ زنده را باز کنید: aideephub.github.io/vibeyaab](https://aideephub.github.io/vibeyaab)

> **English:** *Find before you build.*  **فارسی:** «قبل از ساختن، پیدا کن.»

VibeYaab یک ابزار جست‌وجوی رایگان، ایستا و دوزبانه (فارسی / English) برای کشف پروژه‌های ساخته‌شده با
هوش مصنوعی («وایب‌کدشده»)، جایگزین‌های متن‌باز، مخزن‌های GitHub و فهرست‌های مرتبط
است — **پیش از آنکه** چیزی مشابه بسازید.

این یک برنامهٔ کاملاً فرانت‌اند است: بدون بک‌اند، بدون پایگاه داده، بدون حساب کاربری، بدون تحلیل‌گر
و بدون تبلیغ. هر چیزی که کاربر می‌سازد (نشانک‌ها، تنظیمات، جست‌وجوهای اخیر) در `localStorage` مرورگر
می‌ماند.

کانال معرفی‌شده: **AIDEEP** · **لایه‌های عمیق هوش مصنوعی** — <https://eitaa.com/AIDEEP>

## ۱. امکانات

- **یک فهرست نتایج یکپارچه** از چند منبع، که به‌صورت موازی با `Promise.allSettled` جست‌وجو می‌شوند
  (اگر یک منبع خطا بدهد، بقیه همچنان نمایش داده می‌شوند، همراه با یک نوار هشدار):
  - **API عمومی VibeKing** (`https://vibeking.fun/api/products`) — منبع ساختاریافتهٔ اصلی
  - **API عمومی One's Vibe** (`https://onesvibe.app/api/reference`) — ساختاریافته و دارای CORS
  - **Google Programmable Search Element** روی دامنه‌ها و فهرست‌های منتخب (اختیاری، نیازمند شناسه)
  - **جست‌وجوی مخزن GitHub** — اختیاری، **به‌طور پیش‌فرض خاموش** (در تنظیمات روشن کنید؛ محدودیت نرخ
    پایین)
  - پیوندهای مرور منتخب: موضوعات GitHub، YourAIProject، Open SaaS Directory، پنج فهرست awesome
- رتبه‌بندی با یک امتیاز ساده و شفاف (به پنل «چرا این نتایج؟» در برنامه مراجعه کنید).
- **جست‌وجوی بین‌زبانی (فارسی ↔ English):** وقتی پرس‌وجو عمدتاً فارسی باشد، معادل‌های انگلیسی آن نیز
  از یک واژه‌نامهٔ محلی و منتخب جست‌وجو می‌شوند (مثلاً «نقاشی» همچنین *drawing, painting, sketch* را
  جست‌وجو می‌کند). نتایج هر دو پرس‌وجو ادغام، بر اساس URL یکتاسازی و با هم رتبه‌بندی
  می‌شوند — پرس‌وجوی اصلی فارسی همیشه جست‌وجو می‌شود و هرگز جایگزین نمی‌شود. واژه‌های استفاده‌شده
  به‌صورت چیپ‌های قابل‌حذف نمایش داده می‌شوند (پیش و پس از جست‌وجو)، و حذف هر کدام جست‌وجو را بدون
  آن از طریق پارامتر `xe=` دوباره اجرا می‌کند. بدون API ترجمه، بدون کلید، و بدون درخواست شبکه
  به‌ازای هر کلید.
- پیوندهای تکراری (http/https، `www.`، اسلش انتهایی، پارامترهای ردیابی) ادغام می‌شوند.
- فیلترها: چیپ‌های محدودهٔ سریع، منبع، دسته‌بندی، ابزار هوش مصنوعی، مرتب‌سازی
  (مرتبط‌بودن / جدیدترین / بیشترین رأی).
- نشانک‌ها با به‌روزرسانی فوری در همه‌جا، خروجی JSON، و ورودی JSON معتبرشده با **ادغام**.
- کاملاً دوزبانه با تغییر فوری، آینه‌سازی صحیح **LTR/RTL**، و پوستهٔ روشن / تاریک / سیستم.
- پشتیبانی از URL: `?q=expense+tracker`، همراه با دکمه‌های عقب/جلو مرورگر.
- PWA قابل‌نصب با صفحهٔ جایگزین آفلاین (در حالت آفلاین نشانک‌ها و تنظیمات نمایش داده می‌شوند؛
  جست‌وجوی زنده به اینترنت نیاز دارد).
- قاعدهٔ صداقت: یک نتیجه فقط زمانی با برچسب «دموی زنده»، «متن‌باز» یا «اضافه‌شده … پیش» نمایش داده
  می‌شود که خود منبع آن اطلاعات را ارائه کند.

## ۲. اجرا روی رایانهٔ خودتان (ویندوز)

بخش نصب را فقط یک بار انجام می‌دهید.

### ۲.۱ نصب Node.js

1. به <https://nodejs.org> بروید و نسخهٔ **LTS** را دانلود کنید (دکمهٔ سبز بزرگ).
2. نصب‌کننده را اجرا کنید و پیوسته **Next** را بزنید (گزینه‌های پیش‌فرض مناسب‌اند).
3. اگر نصب‌کننده پیشنهاد داد، رایانه را دوباره راه‌اندازی کنید.

بررسی موفقیت: کلید **Windows** را بزنید، `PowerShell` را تایپ کنید، **Enter** بزنید، سپس تایپ کنید:

```powershell
node -v
npm -v
```

باید دو شمارهٔ نسخه ببینید (مثلاً `v20.x.x` و `10.x.x`).

### ۲.۲ باز کردن پوشهٔ پروژه در PowerShell

1. پوشهٔ پروژه را جایی ساده بگذارید، مثلاً `C:\vibeyaab`.
2. در PowerShell وارد آن شوید:

```powershell
cd C:\vibeyaab
```

(نکته: در File Explorer پوشه را باز کنید، نوار آدرس را کلیک کنید، `powershell` تایپ کنید و Enter
بزنید — PowerShell از همان‌جا باز می‌شود.)

### ۲.۳ نصب بلوک‌های سازندهٔ پروژه (یک‌بار)

```powershell
npm install
```

حدود یک دقیقه طول می‌کشد و پوشهٔ `node_modules` ساخته می‌شود. هشدارها طبیعی‌اند؛ **خطاهای** قرمز نه.

### ۲.۴ اجرای محلی برنامه

```powershell
npm run dev
```

در PowerShell پیوندی مثل `http://localhost:5173/` چاپ می‌کند. **Ctrl** را نگه دارید و کلیک کنید (یا در مرورگر کپی کنید). هر زمان با **Ctrl + C** در PowerShell متوقف کنید

### ۲.۵ (اختیاری) ساخت نسخهٔ تولید

```powershell
npm run build
```

پوشهٔ `dist` ساخته می‌شود — همان وب‌سایت نهایی. برای پیش‌نمایش دقیق آنچه منتشر می‌شود:

```powershell
npm run preview
```

## ۳. انتشار روی GitHub Pages (گام‌به‌گام)

GitHub Pages سایت را به‌صورت رایگان در `https://YOUR-USERNAME.github.io/vibeyaab/` میزبانی می‌کند.

### ۳.۱ ساخت حساب GitHub و مخزن

1. در <https://github.com> ثبت‌نام کنید (رایگان).
2. روی **+** (بالا سمت راست) → **New repository** کلیک کنید.
3. نام مخزن: **`vibeyaab`** (حروف کوچک؛ این بخشی از آدرس سایت شما می‌شود).
4. **Public** را انتخاب کنید. تیک «Add a README» را **نزنید** (پروژه از قبل README دارد).
5. **Create repository** را بزنید. صفحه را باز نگه دارید — آدرس مخزن را نشان می‌دهد، مثل
   `https://github.com/YOUR-USERNAME/vibeyaab.git`.

### ۳.۲ بارگذاری پروژه از رایانهٔ خودتان

**گزینهٔ الف — با Git (پیشنهادی).**

1. اپ Git for Windows را از <https://git-scm.com/download/win> نصب کنید (گزینه‌های پیش‌فرض مناسب‌اند)،
   سپس یک پنجرهٔ **جدید** PowerShell باز کنید.
2. تنظیم یک‌بارهٔ هویت (نام و ایمیل خودتان):

   ```powershell
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

3. در پوشهٔ پروژه (`cd C:\vibeyaab`)، این خطوط را یکی‌یکی اجرا کنید (به‌جای `YOUR-USERNAME` نام
   کاربری خود را بگذارید):

   ```powershell
   git init
   git add .
   git commit -m "First version of VibeYaab"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/vibeyaab.git
   git push -u origin main
   ```

4. ممکن است پنجره‌ای از مرورگر برای ورود به GitHub باز شود — وارد شوید و تأیید کنید.

**گزینهٔ ب — با GitHub Desktop (بدون دستور).**

1. اپ <https://desktop.github.com> را نصب و وارد شوید.
2. در **File → Add local repository…** → پوشهٔ پروژه را انتخاب کنید → وقتی پرسید
   و **create a repository** را بزنید → **Create repository**.
3. عبارت **Publish repository** را بزنید، نامش را `vibeyaab` بگذارید، تیک «Keep this code private» را بردارید، **Publish**.

> پوشه‌های `node_modules` و `dist` را **بارگذاری نکنید**. فایل `.gitignore` موجود از این کار با Git
  و GitHub Desktop جلوگیری می‌کند. همچنین مطمئن شوید پوشهٔ مخفی `.github` بارگذاری شده — دستور
  انتشار خودکار در آن است.

### ۳.۳ فعال‌سازی GitHub Pages

1. در مخزن خود در github.com به **Settings** → **Pages** (منوی چپ) بروید.
2. زیر **Build and deployment → Source**، گزینهٔ **GitHub Actions** را انتخاب کنید.

### ۳.۴ انتظار برای ساخت خودکار

1. تب **Actions** را باز کنید. اجرایی به نام **Deploy VibeYaab to GitHub Pages** پس از هر بارگذاری
   (push) خودبه‌خود شروع می‌شود. منتظر تیک سبز بمانید (حدود ۱–۲ دقیقه).
2. **Settings → Pages** را باز کنید: آدرس سایت در بالا نمایش داده می‌شود، مثل
   `https://YOUR-USERNAME.github.io/vibeyaab/`. بازش کنید — زنده شده‌اید.

اگر اجرا ✗ قرمز نشان داد، روی آن کلیک کنید، سپس روی گام ناموفق، و پیام را بخوانید (به
[رفع اشکال](#۸-رفع-اشکال) مراجعه کنید).

### ۳.۵ استفاده از نام مخزن متفاوت

برنامه از پیوندهای نسبی استفاده می‌کند، بنابراین تحت **هر** نام مخزنی (و در ریشهٔ دامنهٔ سفارشی)
بدون تغییر تنظیمات کار می‌کند. فقط همان نام را در آدرس خود به کار ببرید.

## ۴. اختیاری: فعال‌سازی نتایج Google

بدون این گام هم VibeYaab کار می‌کند (VibeKing + One's Vibe + پیوندها). Google پوشش بیشتری روی
GitHub، YourAIProject، Open SaaS Directory و فهرست‌های awesome اضافه می‌کند.

### ۴.۱ ساخت موتور جست‌وجو

1. <https://programmablesearchengine.google.com/> را باز کنید و با حساب Google وارد شوید.
2. **Add** را بزنید (ساخت موتور جست‌وجوی جدید).
3. نامی مثل `VibeYaab` بگذارید.
4. **Search specific sites or pages** را انتخاب کنید و هر یک از این‌ها را اضافه کنید (هر خط
   یکی / یکی‌یکی):

   ```text
   vibeking.fun/*
   youraiproject.com/*
   github.com/*
   opensaas.directory/*
   github.com/JefferyLee/awesome-vibe-coded-apps/*
   github.com/0xWelt/Awesome-Vibe-Coding/*
   github.com/awesome-vibe-coding/awesome-vibe-coding/*
   github.com/Anil-matcha/awesome-vibecoded-saas/*
   github.com/archestack/best-of-vibe-coding/*
   ```

5. تیک پرسش «I'm not a robot» را بزنید و **Create** را بزنید.
6. موتور جدید را باز کنید → **Overview** → **Search engine ID** را کپی کنید
   (مقداری مثل `a1b2c3d4e5f6g7h8i`).

اپ VibeYaab نتایج Google را در طراحی خودش نمایش می‌دهد و هرگز تبلیغات Google را نشان نمی‌دهد. Google
ممکن است محدودیت‌های استفادهٔ خود را روی Element رایگان اعمال کند.

### ۴.۲ دادن شناسه به برنامه

- **روی GitHub Pages:** مخزن → **Settings → Secrets and variables → Actions → تب Variables** →
  **New repository variable** → نام `VITE_GOOGLE_CSE_ID`، مقدار = شناسهٔ شما → **Add variable**. سپس
  تب **Actions** را باز کنید، آخرین اجرا را انتخاب و **Re-run all jobs** را بزنید (یا تغییر کوچکی
  بدهید و push کنید).
- **به‌صورت محلی:** `.env.example` را به `.env` کپی کنید (در PowerShell: `copy .env.example .env`)،
  `.env` را در Notepad باز کنید و `your_programmable_search_engine_id` را با شناسهٔ خود عوض کنید.
  `npm run dev` را دوباره راه‌اندازی کنید.

شناسه به‌طور طراحی‌شده عمومی است (در کد وب‌سایت قرار می‌گیرد)؛ **رمز عبور نیست**. اسکریپت Google فقط
پس از اجرای یک جست‌وجو و تنها وقتی شناسه تنظیم شده باشد بارگذاری می‌شود.

## ۵. به‌روزرسانی سایت در آینده

پس از تغییر هر فایل:

```powershell
git add .
git commit -m "Describe your change"
git push
```

سایت GitHub به‌طور خودکار دوباره می‌سازد و منتشر می‌کند (تب **Actions** را ببینید). با GitHub Desktop:
خلاصه بنویسید → **Commit to main** → **Push origin**.

کاربران PWA نصب‌شده نسخهٔ جدید را دفعهٔ بعد که برنامه را آنلاین باز کنند دریافت می‌کنند (ممکن است
لازم باشد یک‌بار ببندید و دوباره باز کنید).

## ۶. نصب به‌عنوان برنامه (PWA)

- **مرورگر Chrome / Edge در ویندوز:** سایت را باز کنید → روی آیکون *install* در انتهای راست نوار آدرس کلیک
  کنید → **Install**.
- **مرورگر Chrome اندروید:** منو (⋮) → **Install app** / **Add to Home screen**.
- **مرورگر Safari آیفون:** دکمهٔ Share → **Add to Home Screen**.

در حالت آفلاین، برنامه باز می‌شود و نشانک‌ها و تنظیمات را نشان می‌دهد؛ جست‌وجو به اتصال اینترنت نیاز
دارد.

## ۷. توضیح خروجی و ورودی داده

**Settings → Export data** فایل `vibeyaab-export-YYYY-MM-DD.json` را دانلود می‌کند:

```json
{
  "app": "VibeYaab",
  "version": 1,
  "exportedAt": "2026-01-01T12:00:00.000Z",
  "settings": { "lang": "en", "theme": "system", "githubApi": false },
  "bookmarks": [
    {
      "id": "bm_…",
      "title": "Example",
      "url": "https://example.com/",
      "source": "vibeking",
      "savedAt": "2026-01-01T12:00:00.000Z"
    }
  ]
}
```

بخش **Settings → Import data** فایل را معتبرسازی می‌کند، سپس خلاصه‌ای نشان می‌دهد (چند نشانک جدید است و
چند تکراری). تا وقتی **Merge into my data** را نزنید چیزی تغییر نمی‌کند. ادغام فقط نشانک‌هایی را
*اضافه* می‌کند که قبلاً ذخیره نشده‌اند (بر اساس URL یکتاسازی‌شده)؛ هرگز حذف یا بازنویسی نمی‌کند.
تنظیمات فایل فقط در صورتی اعمال می‌شوند که تیک بزنید.

گزینۀ **Clear all local data** (با تأیید) نشانک‌ها، جست‌وجوهای اخیر و تنظیمات را از این مرورگر پاک می‌کند.

## ۱۰. نحوهٔ کار (برای توسعه‌دهندگان)

```text
src/
├── App.tsx                 پوسته: هدر، مسیریابی، همگام‌سازی <html lang/dir/theme>، نوار آفلاین
├── i18n/                   en.ts (منبع حقیقت)، fa.ts (از نظر نوع با en بررسی می‌شود)، useI18n()
├── data/
│   └── persianEnglishDictionary.ts   واژه‌های جست‌وجوی فارسی → انگلیسی منتخب (پایین را ببینید)
├── lib/
│   ├── storage.ts          مخزن‌های localStorage (تنظیمات، جست‌وجوهای اخیر) با useSyncExternalStore
│   ├── bookmarks.ts        مخزن نشانک، اعتبارسنجی، ادغام، خروجی/ورودی
│   ├── router.ts           مسیریاب کوچک: ?q=…&f=…&xe=… برای جست‌وجوها، #/bookmarks و غیره برای صفحه‌ها
│   ├── language.ts         تشخیص خط فارسی + نرمال‌سازی املایی
│   ├── queryExpansion.ts   جست‌وجوی واژه‌نامهٔ محلی: پرس‌وجوی فارسی → واژه‌های جست‌وجوی انگلیسی
│   ├── search.ts           اجراکنندهٔ موازی (Promise.allSettled)، فیلترها، وجوه
│   ├── ranking.ts          امتیازدهی وزنی شفاف (تطبیق‌های بسط‌یافته کمی کمتر حساب می‌شوند)
│   ├── dedupe.ts           ادغام نتایج بر اساس URL یکتاسازی‌شده
│   └── useSearch.ts        هوک: وضعیت هر منبع، خطاهای جزئی، «بیشتر»، جست‌وجوی دو دوری
├── sources/                آداپتورهای SearchSource: vibeking، onesvibe، googleCse، github (+ پیوندهای منتخب)
├── components/  pages/     رابط کاربری
└── styles/                 tokens.css (پوسته‌ها) + global.css (فقط ویژگی‌های منطقی CSS)
public/                     manifest، icons، offline.html، sw.js (service worker)
```

- **افزودن منبع:** `src/sources/mysource.ts` را بسازید که یک `SearchSource` صادر کند
  (`id`، `label`، `search()`، `isEnabled()`)، سپس آن را به `ALL_SOURCES` در `src/sources/index.ts`
  اضافه کنید.
- **گسترش واژه‌نامهٔ بین‌زبانی:** برای هر واژهٔ فارسی یک خط به
  `src/data/persianEnglishDictionary.ts` اضافه کنید (توضیح نحوهٔ کار در بالای همان فایل است).
  جست‌وجو ی/ک، ZWNJ، اعراب و شکل‌های همزه را خودکار نرمال می‌کند، پس برای هر واژه یک کلید بنویسید.
  واژه‌های انگلیسی به‌صورت یک پرس‌وجوی اضافیِ به‌هم‌پیوسته به هر منبع فرستاده می‌شوند و به کاربر
  به‌صورت چیپ‌های قابل‌حذف نمایش داده می‌شوند؛ چیز دیگری نیاز به تغییر ندارد.
- **یکپارچه‌سازی Google:** Programmable Search Element در حالت `searchresults-only` داخل یک ظرف مخفی
  اجرا می‌شود. کال‌بک «results ready» آن نتایج خام را به VibeYaab می‌دهد (و مانع رسم نشانه‌گذاری خود
  Google می‌شود) تا به فهرست یکپارچه، رتبه‌بندی‌شده و قابل‌نشانک‌گذاری بپیوندند.
- **مسیر GitHub Pages:** همهٔ آدرس‌های دارایی در `index.html`، manifest و service worker نسبی‌اند، و
  برنامه JS/CSS خود را در یک `index.html` واحد درون‌خط می‌کند، بنابراین هیچ تنظیم `base` لازم نیست.
- **Service worker:** پوستهٔ برنامه را کش می‌کند؛ ناوبری شبکه‌اول است؛ درخواست‌های میان‌مبدأ (همهٔ
  APIهای جست‌وجو) هرگز رهگیری یا کش نمی‌شوند.
- **گزینۀ RTL:** CSS از ویژگی‌های منطقی استفاده می‌کند (`margin-inline`، `inset-inline-start`، …)؛
  آیکون‌های جهت‌دار از کلاس `.icon-mirror` استفاده می‌کنند.
- دستورها: `npm run dev`، `npm run build`، `npm run preview`، و `npx tsc --noEmit` برای بررسی نوع.
