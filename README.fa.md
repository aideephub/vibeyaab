# وایبیاب (VibeYaab) — پیش از ساختن، پیدا کن

## ▶️ [برنامهٔ زنده را باز کنید](https://aideephub.github.io/vibeyaab)

**فارسی** · [English](./README.md)

وایبیاب (VibeYaab) یک ابزار جست‌وجوی رایگان و دوزبانه (فارسی / English) است
برای پیدا کردن چیزی که همین حالا وجود دارد — برنامه‌های ساخته‌شده با هوش
مصنوعی («وایب‌کدشده»)، جایگزین‌های متن‌باز، مخزن‌های GitHub و فهرست‌های
منتخب — تا **پیش از** صرف یک آخر هفته برای ساختن چیزی که شخص دیگری منتشر کرده
است، بدانید چه هست و چه نیست.

یک کادر جست‌وجو و یک فهرست رتبه‌بندی‌شده — نسخهٔ زنده
در <https://aideephub.github.io/vibeyaab>. بدون حساب کاربری، بدون بک‌اند و
بدون تحلیل‌گر؛ هر چیزی که ذخیره می‌کنید در مرورگر خودتان می‌ماند.

## امکانات

- **یک فهرست رتبه‌بندی‌شده از چند منبع.** ویبکینگ (VibeKing)،
  سرویس One's Vibe، جست‌وجوی GitHub و چند فهرست منتخب به‌صورت موازی جست‌وجو و
  سپس ادغام می‌شوند. اگر یک منبع قطع یا محدود شده باشد، بقیه نمایش داده
  می‌شوند و یک یادداشت کوتاه جای صفحهٔ خالی را می‌گیرد.
- **فارسی جست‌وجو کنید، پروژه‌های انگلیسی را پیدا کنید.** پرس‌وجوی عمدتاً
  فارسی با معادل‌های انگلیسیِ برگرفته از یک واژه‌نامهٔ داخلی هم جست‌وجو
  می‌شود؛ مثلاً واژهٔ «نقاشی» معادل‌های *drawing*، *painting* و *sketch* را هم
  امتحان می‌کند. هر دو مجموعه ادغام، بر اساس URL یکتاسازی و با هم رتبه‌بندی
  می‌شوند. واژه‌های اضافه به‌صورت چیپ‌های قابل‌حذف نمایش داده می‌شوند و حذف هر
  کدام، جست‌وجو را بدون آن دوباره اجرا می‌کند. بدون API ترجمه، بدون کلید و
  بدون درخواست به‌ازای هر کلید فشرده.
- **بدون نتیجهٔ تکراری.** تفاوت‌های http/https، `www.`، اسلش انتهایی و
  پارامترهای ردیابی پیش از ادغام یکسان‌سازی می‌شوند.
- **فیلترهایی که واقعاً به کار می‌آیند.** منبع، دسته‌بندی، ابزار هوش مصنوعی و
  مرتب‌سازی (مرتبط‌بودن، جدیدترین، بیشترین رأی)، همراه با چیپ‌های محدودهٔ سریع
  برای جست‌وجوهای رایج.
- **رتبه‌بندی شفاف.** هر نتیجه یک امتیاز روشن دارد و پنل «چرا این نتایج؟»
  توضیح می‌دهد که این ترتیب از کجا آمده است.
- **برچسب‌ها فقط وقتی درست‌اند که منبع بگوید.** یک نتیجه تنها زمانی با «دموی
  زنده»، «متن‌باز» یا «اضافه‌شده … پیش» علامت می‌خورد که خود منبع آن اطلاعات
  را بدهد.
- **نشانک‌هایی که مال خودتان است.** ذخیره در همه‌جای برنامه فوری است؛
  خروجی JSON دارید و ورودی با اعتبارسنجی و **ادغام** انجام می‌شود — ادغام فقط
  اضافه می‌کند و هرگز پاک یا بازنویسی نمی‌کند.
- **در هر دو جهت درست کار می‌کند.** جابه‌جایی فوری بین فارسی و English با
  آینه‌سازی صحیح چیدمان راست‌به‌چپ و چپ‌به‌راست، به‌همراه پوستهٔ روشن، تاریک و
  سیستم.
- **قابل نصب، با رفتار روشن در حالت آفلاین.** یک PWA با صفحهٔ جایگزین آفلاین
  که نشانک‌ها و تنظیمات را نشان می‌دهد؛ جست‌وجوی زنده به اتصال اینترنت نیاز
  دارد.

## نتایج از کجا می‌آید

- **ویبکینگ (VibeKing)** — API عمومی محصول‌ها؛ منبع ساختاریافتهٔ اصلی.
- **سرویس One's Vibe** — API عمومی مرجع با پشتیبانی CORS.
- **جست‌وجوی GitHub** — به‌طور پیش‌فرض خاموش است چون محدودیت نرخ پایینی دارد؛
  از تنظیمات روشنش کنید.
- **جست‌وجوی Google** — اختیاری؛ وقتی راه‌اندازنده شناسهٔ موتور جست‌وجو را
  تنظیم کند، مجموعه‌ای منتخب از دامنه‌ها و فهرست‌های awesome را پوشش می‌دهد.
- **پیوندهای منتخب** — موضوعات GitHub، YourAIProject، Open SaaS Directory و
  پنج فهرست awesome، همیشه قابل مرور.

## طرز استفاده

1. برنامهٔ زنده را باز کنید: <https://aideephub.github.io/vibeyaab>
2. بنویسید چه چیزی می‌خواهید بسازید — فارسی یا انگلیسی.
3. فهرست را با فیلترها باریک کنید و آنچه ارزش نگه‌داشتن دارد را نشانک کنید.
4. اگر زیاد استفاده می‌کنید، از منوی مرورگر نصبش کنید (*Install*
   یا *Add to Home screen*).

هر جست‌وجو در URL می‌ماند (`?q=…`)، پس دکمه‌های عقب و جلو کار می‌کنند و هر
جست‌وجو را می‌توان به‌صورت یک پیوند به اشتراک گذاشت.

## حریم خصوصی

هیچ بک‌اند، پایگاه داده، حساب کاربری یا تحلیل‌گری وجود ندارد. نشانک‌ها،
تنظیمات و جست‌وجوهای اخیر در `localStorage` مرورگر شما می‌مانند و هیچ‌جا
فرستاده نمی‌شوند. پرس‌وجوها مستقیماً از مرورگر شما به منابع جست‌وجوی بالا
می‌روند.

## توسعه

پروژه با React، TypeScript و Vite ساخته شده است. نسخهٔ تولیدی، JS و CSS را در
یک فایل `index.html` واحد درون‌خط می‌کند؛ به همین دلیل برنامه از هر مسیری — از
جمله زیرمسیر GitHub Pages — بدون تنظیم `base` کار می‌کند.

```bash
npm install
npm run dev       # اجرای محلی
npm run build     # ساخت نسخهٔ تولیدی در dist/
npm run preview   # پیش‌نمایش نسخهٔ تولیدی
npx tsc --noEmit  # بررسی نوع‌ها
```

هر push به شاخهٔ `main` توسط گردش‌کار موجود در `.github/workflows` ساخته و
روی GitHub Pages منتشر می‌شود.

- **متغیر اختیاری ساخت:** `VITE_GOOGLE_CSE_ID`
  (شناسهٔ Google Programmable Search Engine). اگر تنظیم نشود، نتایج Google
  نادیده گرفته می‌شوند و بقیهٔ برنامه کار می‌کند. این شناسه به‌طور طراحی‌شده
  عمومی است و رمز نیست.
- **افزودن منبع:** رابط `SearchSource` را در فایلی تازه زیر `src/sources/`
  پیاده کنید و آن را در `src/sources/index.ts` ثبت کنید.
- **گسترش واژه‌نامه:** برای هر واژهٔ فارسی یک خط
  به `src/data/persianEnglishDictionary.ts` اضافه کنید.

مشارکت، گزارش خطا و پیشنهاد منبع خوش‌آمد است.
